# The Price of Ageing in Health: Is Age Just a Number?
#Brief Description
This analysis tests the Red Herring Hypothesis that argues that it is not necessarily ageing that drives medical costs, but proximity to death regardless of age. the Main hypothesis is that the effect of age on healthcare spending becomes statistically insignificant when TTD is included. this is highly debated and just as understudied in the african context where ageing populations are expected to triple by 2050. this analysis uses Malawi LSMS data to analyse health spending and make recommendations to policy with regards to the ageing.

# Files Uploaded
* the dataset is cleaned version of the IHS5
* the dofile contains the script to test the code, used for cleaning, analysis and visualisation. The scripts automate various statistical tasks and generate reproducible outputs.

# Results
* Red Herring Hypothesis holds weight: Findings support that proximity to death (TTD) is a stronger predictor of healthcare expenditure than chronological age.

* Age alone is insufficient: Once TTD and comorbidities are controlled for, the impact of age on healthcare costs becomes statistically insignificant.

* Policy implication: Targeting health interventions around end-of-life care and chronic conditions may yield greater efficiency than age-based models.
